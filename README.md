# Wardrobe Mate

数字衣橱与日常穿搭助手：整理已经拥有的衣服，结合天气、场景和个人偏好，减少每天决定穿什么的负担。

> 当前状态：后端起步代码阶段。已加入衣物与搭配的基础管理接口，完整产品仍在规划中。

## 当前代码

`backend/main.py` 提供 FastAPI 后端入口：

- 健康检查：`GET /health`。
- 衣物管理：新增、列表、详情、完整更新和删除，支持按分类及可用状态筛选。
- 搭配管理：新增、列表、详情、完整更新和删除。
- 保存搭配时检查单品是否存在、是否可用及是否重复；被搭配引用的衣物不能直接删除。

目前数据仅保存在单个进程的内存中，重启即丢失，多进程之间不共享。尚未实现账号隔离，适合本地原型开发。

## 本地启动

需要 Python 3.11 或更高版本。在仓库根目录执行以下 PowerShell 命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload
```

启动后的交互式接口文档地址为 `http://127.0.0.1:8000/docs`。图片地址仅作为衣物信息保存，当前不下载或处理图片。

## 为什么做

衣服不少，却常常不知道怎么搭；喜欢的搭配难以复用，天气变化时也缺少合适的参考。

Wardrobe Mate 希望把个人衣物整理、自由搭配和日常建议放在同一个工具里。推荐以用户真实拥有的衣服为基础，帮助用户穿好现有衣橱。

## 面向谁

- 希望整理个人衣橱、减少重复购买的人。
- 希望按天气和出行场景快速决定穿搭的人。
- 喜欢尝试搭配，并希望保存和回顾穿搭的人。

项目面向个人开发者或中小型团队推进，优先控制维护负担和外部服务成本。

## 计划提供的能力

| 能力 | 预期体验 |
| --- | --- |
| 数字衣橱 | 拍照或从相册导入衣物，分类整理，维护衣物状态 |
| AI 辅助整理 | 辅助去背景、识别衣物属性，支持用户确认和修正 |
| 自由搭配画布 | 拖拽、缩放、旋转衣物，调整层级，保存搭配并导出图片 |
| 每日穿搭建议 | 综合天气、场合、可用衣物和个人偏好提供建议 |
| 局部调整 | 保留喜欢的单品，替换其他部分 |
| 穿搭记录 | 保存穿着记录和反馈，帮助后续建议更贴合个人习惯 |

上表描述完整产品的规划体验。当前代码仅覆盖基础数据管理接口，尚无移动端页面、搭配画布、AI 处理或推荐能力。

## 架构方向

**端侧重交互、后端保持轻量、AI 能力通过接口接入、推荐采用规则与大模型协作。**

- 优先把衣橱浏览、搭配画布和适合端侧的图像处理放在客户端。
- 后端负责业务数据、服务协调和推荐流程，早期不自训模型、不自建 GPU 服务。
- 先根据衣物和环境约束形成候选搭配，再按需让大模型辅助排序和解释。
- 外部服务不可用时，保留衣橱管理和手动搭配的基本体验。

移动端拟优先考虑 Flutter，后端拟优先考虑 Python / FastAPI，数据存储拟以 PostgreSQL 和对象存储为主。具体选型仍需验证，详见高层架构文档。
