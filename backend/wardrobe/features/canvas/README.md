# 画布布局元数据

保存尺寸与衣物图层变换，不提供画布 UI、图片下载、合成或导出。

| 接口 | 用途 |
| --- | --- |
| `GET /canvas/{outfit_id}` | 读取保存的布局 |
| `PUT /canvas/{outfit_id}` | 创建或完整替换布局 |
| `DELETE /canvas/{outfit_id}` | 删除布局 |

保存时搭配必须存在，每个图层必须对应当前搭配内的真实衣物。
尺寸限制为 100 到 8192，同一单品不能重复出现，坐标和变换必须是有限数值。

搭配后来被删除时，已有布局仍可读取，并返回 `outfit_exists: false`。
衣物被删除或移出搭配后进入 `missing_item_ids`；不可用衣物进入 `unavailable_item_ids`。
布局允许包含当前不可用衣物，但会明确返回状态。

全部数据只存内存，重启丢失，多进程不共享。
