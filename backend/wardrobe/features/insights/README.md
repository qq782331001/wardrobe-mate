# 穿着洞察

`GET /insights?as_of=2026-11-19&days=30` 汇总指定窗口内的实际记录。
必须显式提供结束日 `as_of`；`days` 范围为 1 到 365，默认 30。
窗口包含起止两天，不使用服务器当前日期或定位时区。

返回内容包括：

- 窗口起止、实际覆盖天数和穿着记录数。
- 喜欢、一般、不喜欢三类反馈数量。
- 每日穿着记录数，没有记录的日期返回零。
- 当前衣橱中，窗口内未关联穿着记录的单品 ID。
- 当前衣橱分类数量，以及窗口内穿过的不同单品分类数量。

单品关联根据当前搭配计算，没有保存历史衣物快照，修改搭配会影响历史汇总。
已失去关联的单品不会被当作当前穿过的真实衣物；穿着记录本身仍计入记录与反馈数量。
本模块只读取当前进程数据，不做预测或 AI 分析。
