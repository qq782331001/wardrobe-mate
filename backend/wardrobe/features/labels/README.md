# 自定义标签

用标签整理衣橱中的衣物，可保存名称、六位 HEX 颜色及关联单品。

| 接口 | 用途 |
| --- | --- |
| `GET /labels` | 标签列表 |
| `POST /labels` | 创建标签 |
| `GET /labels/{id}` | 标签详情 |
| `PUT /labels/{id}` | 完整更新标签 |
| `DELETE /labels/{id}` | 删除标签，保留衣物 |

名称忽略大小写后唯一，重复返回 409。每个标签最多关联 200 件不同衣物，写入时检查引用存在。

衣物之后被删除时，标签保留原引用，返回的 `missing_item_ids` 会标明失效衣物。更新时需要先移除失效引用。

仅使用本地进程内存；重启丢失，无账号隔离。示例见 `requests/labels.http`。
