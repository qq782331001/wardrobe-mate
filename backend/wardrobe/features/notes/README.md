# 备注

为已有衣物或搭配保存文字备注，每条最多 2000 字符。

| 接口 | 用途 |
| --- | --- |
| `GET /notes` | 列表，可按目标类型和 ID 筛选 |
| `POST /notes` | 新建备注 |
| `GET /notes/{id}` | 备注详情 |
| `PUT /notes/{id}` | 完整更新备注 |
| `DELETE /notes/{id}` | 删除备注 |

目标类型为 `item` 或 `outfit`，新增和修改时要求引用目标存在。一个目标可以有多条备注。

核心目标之后被删除时，历史备注仍保留，`target_exists` 会变为 `false`；更新前需要选择仍存在的目标。

数据仅保存于当前进程，重启丢失，无账号隔离。示例见 `requests/notes.http`。
