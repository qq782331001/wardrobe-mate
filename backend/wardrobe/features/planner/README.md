# 穿搭计划

为已有搭配安排日期与场合，日期始终由用户提供，不从服务主机推断今天。

| 方法与路径 | 用途 |
| --- | --- |
| `POST /planner` | 新增计划 |
| `GET /planner?start_date=2026-11-19&end_date=2026-11-30` | 按日期范围查询 |
| `GET /planner/{id}` | 查看计划 |
| `PUT /planner/{id}` | 完整更新计划 |
| `DELETE /planner/{id}` | 删除计划 |

日期区间包含起止两端，开始日期晚于结束日期时返回输入错误。
创建与更新要求搭配存在，不保证计划日期当天的衣物状态或天气合适。
搭配后来被删除，计划仍保留，并通过 `outfit_exists: false` 标识。
计划不等于实际穿着记录，不会自动写入 `/wear-logs` 或触发通知。
数据仅存进程内，重启清空，多进程不共享，尚无账号隔离。
