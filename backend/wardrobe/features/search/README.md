# 纯文本搜索

`GET /search?q=白色&limit=20` 同时搜索当前衣物与搭配。

| 字段 | 含义 |
| --- | --- |
| `items` | 匹配的衣物 |
| `outfits` | 匹配的搭配 |
| `item_total` | 截取前的衣物匹配总数 |
| `outfit_total` | 截取前的搭配匹配总数 |

匹配字段为衣物名称、颜色，以及搭配名称、场景。
关键字去除两端空白后进行不区分大小写的子串搜索，纯空白返回 422。
每类结果按名称和 ID 稳定排序，分别最多返回 `limit` 条，范围为 1 到 100。

不接入语义向量、图片识别或大模型，也不会自动匹配同义词。
结果直接读取当前进程数据，不单独保存搜索索引。
